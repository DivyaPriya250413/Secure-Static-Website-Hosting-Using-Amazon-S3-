**🚀 Project : Secure Static Website Hosting Using Amazon S3! ☁️**

Today, I worked on hosting a static website on Amazon Web Services (AWS) S3 by uploading my `index.html` file and managing website access.

**🛠️ Technologies Used:**

Amazon S3 | AWS IAM | Bucket Policies | Cloud Storage | AWS Cloud

**💻 What I implemented:**

✅ Created an S3 bucket and uploaded website files
✅ Configured bucket policies and access permissions
✅ Explored IAM permissions and public/private access controls
✅ Verified the uploaded website object through the S3 console
✅ Learned how to manage secure access to static website content

**💡 What I learned:**

🔹I gained hands-on experience with Amazon S3 object storage, bucket policies, IAM permissions, cloud security, and static website hosting.

**💰 Cost & Billing:**

🔹I also explored the cost aspects of hosting a static website on Amazon S3, including storage, requests, and data transfer. 
🔹The overall cost depends on usage and the AWS pricing plan.
